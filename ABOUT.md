# About AgnesCode

AgnesCode is a terminal-native AI coding agent, built as a fork of [OpenCode](https://github.com/anomalyco/opencode).

## What makes AgnesCode different

- **Built-in Agnes AI** — Comes pre-configured with the Agnes AI provider (free multimodal API for text, image, and video)
- **Purple theme** — "Agnes Purple" default color scheme with pulsing ring animation
- **Zero-config start** — Enter your Agnes API key on first launch and start coding immediately

## Core capabilities

- Full TUI (terminal UI) with sidebar, diff viewer, command palette
- Multiple LLM providers (OpenAI-compatible)
- LSP integration for code intelligence
- MCP server support
- Plugin system
- Customizable themes and keybindings

## Project status

AgnesCode is in early development (v0.1.0). It is functional for daily development use but may have rough edges.

## Relationship to OpenCode

AgnesCode is a fork of [OpenCode](https://github.com/anomalyco/opencode). It inherits OpenCode's core architecture (TUI, multi-provider, LSP, MCP, plugins) and replaces the default provider with Agnes AI. We are grateful to the OpenCode team for their foundational work.
